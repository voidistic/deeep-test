موقع يجمع جميع روابط متجر **عالم الرفاهة للألعاب** في مكان واحد.

## 🚀 النشر على GitHub Pages
1. ضع الملفات `index.html` و `logo.png` و `README.md` في مستودع جديد.
2. إعدادات المستودع → Pages → اختر فرع `main` والمجلد `/`.
3. موقعك سيكون: `https://[username].github.io/[repo-name]`

## 🖼️ تغيير الشعار
- استبدل ملف `logo.png` بشعار متجرك (مع الاحتفاظ بنفس الاسم).
- يدعم PNG, JPG, WEBP.
